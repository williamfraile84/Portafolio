## 📁 Estructura de Proyectos (4 Pilares de Software)

Ecosistema técnico estructurado en 4 pilares estratégicos y sus 7 repositorios oficiales:

### 1. Ecosistema Comercial & Hardware: FRUVER POS
Sistema integral de punto de venta, control de inventario y pesaje serial en tiempo real con persistencia dual (**FastAPI + SQLite WAL / PostgreSQL**):
- **Frontend Inventario:** [github.com/williamfraile84/Frontend-Inventario](https://github.com/williamfraile84/Frontend-Inventario)
- **Backend Inventario:** [github.com/williamfraile84/Backend-Inventario](https://github.com/williamfraile84/Backend-Inventario)
- **Control de Báscula POS:** [github.com/williamfraile84/Fruver-POS](https://github.com/williamfraile84/Fruver-POS)

### 2. Logística & Almacenamiento Multi-Cloud: Sistema de Remisiones
Plataforma empresarial para emisión, control logístico y liquidación de remisiones con respaldo documental redundante en **AWS S3** y **Google Drive API** (61 tests automatizados):
- **Frontend Remisiones:** [github.com/williamfraile84/Frontend-Remisiones](https://github.com/williamfraile84/Frontend-Remisiones)
- **Backend Remisiones:** [github.com/williamfraile84/Backend-Remisiones](https://github.com/williamfraile84/Backend-Remisiones)

### 3. Seguridad & Auditoría Forense: Portal Pericial CNG
Plataforma web de auditoría forense y divulgación pericial técnica estructurada bajo los estándares **OWASP Top 10**, **ISO/IEC 25010** y aislamiento transaccional **SQL Server RCSI**:
- **Repositorio Auditoría CNG:** [github.com/williamfraile84/Auditoria-CNG-web](https://github.com/williamfraile84/Auditoria-CNG-web)

### 4. Desarrollo Móvil Nativo & OCR: HanziMemo
Aplicación móvil nativa en **Kotlin y Jetpack Compose** con algoritmos de repetición espaciada (SRS) y procesamiento de visión artificial OCR 100% offline:
- **Repositorio HANZI-APP:** [github.com/williamfraile84/HANZI-APP](https://github.com/williamfraile84/HANZI-APP)
