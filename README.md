## 🚀 Visión General

Este repositorio aloja el código fuente y el despliegue del portafolio profesional de **William Yovany Fraile Bautista**, Ingeniero de Sistemas especializado en desarrollo Full Stack y seguridad de software.

### Características Principales:
- **Arquitectura React 19 Moderna:** Interfaz reactiva desacoplada, diseño en modo oscuro con efectos lumínicos y componentes reutilizables.
- **Sincronización Dinámica con GitHub API:** Consulta en vivo los repositorios públicos del perfil para mostrar métricas de actualización, estrellas y lenguajes.
- **Visor de Capturas Interactivo (Lightbox):** Permite explorar las interfaces de los sistemas en alta resolución sin necesidad de clonar ni configurar los proyectos.
- **Rendimiento Optimizado:** Carga ultrarrápida, rutas relativas y diseño 100% responsivo para dispositivos móviles, tablets y escritorios.

## 📁 Proyectos Destacados

1. **FRUVER POS (Ecosistema Full Stack & Hardware):**  
   - Punto de venta, gestión de inventarios con persistencia dual (**FastAPI + SQLite WAL / PostgreSQL**) e integración de básculas seriales en tiempo real.
   - [Frontend Inventario](https://github.com/williamfraile84/Frontend-Inventario) · [Backend Inventario](https://github.com/williamfraile84/Backend-Inventario) · [Báscula POS](https://github.com/williamfraile84/Fruver-POS)

2. **Sistema de Remisiones & Multi-Cloud:**  
   - Control logístico y almacenamiento documental multi-proveedor (**AWS S3 + Google Drive API**), respaldado por 61 pruebas automatizadas.
   - [Frontend Remisiones](https://github.com/williamfraile84/Frontend-Remisiones) · [Backend Remisiones](https://github.com/williamfraile84/Backend-Remisiones)

3. **Portal Web Pericial CNG:**  
   - Portal interactivo de divulgación de dictámenes periciales forenses bajo estándares **OWASP Top 10**, **ISO/IEC 25010** y aislamiento **SQL Server RCSI**.
   - [Auditoría CNG](https://github.com/williamfraile84/Auditoria-CNG-web) · [Demo en Vivo](https://williamfraile84.github.io/Auditoria-CNG-web/)

4. **HanziMemo (Android Nativo):**  
   - Aplicación móvil en **Kotlin & Jetpack Compose** con algoritmos de repetición espaciada (SRS) y OCR de visión artificial 100% offline.
   - [HANZI-APP](https://github.com/williamfraile84/HANZI-APP)

## 🛠️ Stack Tecnológico

- **Frontend:** React 19, Vite 6, Tailwind CSS, Lucide Icons.
- **Integraciones:** GitHub REST API v3, Web Cryptography API.
- **Despliegue:** GitHub Pages con soporte SPA y optimización de assets.

## 💻 Ejecución Local

Para clonar y ejecutar este proyecto en tu entorno de desarrollo:

```bash
# 1. Clonar el repositorio
git clone https://github.com/williamfraile84/Portafolio.git
cd Portafolio

# 2. Instalar dependencias
npm install

# 3. Iniciar servidor de desarrollo
npm run dev
```
